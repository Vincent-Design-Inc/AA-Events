# Changelog

## [v1.7.6] - 2026-10-29

- Fixed recurring events with selected weekdays ignoring the repeat interval, causing events set to every two weeks to appear weekly.

## [v1.7.5] - 2026-10-26

- Added per-occurrence calendar saving with Google Calendar, Outlook.com, Microsoft 365, and ICS downloads for Apple Calendar and other apps.
- Added calendar choices to dates loaded with "Show next," with notices for estimated end times and saved copies that do not sync.
- Restricted calendar downloads and occurrence pagination to public, published, non-password-protected events.

## [v1.7.0] - 2026-10-14

- Add support for plugin updates from Github

## [v1.6.5] - 2026-10-14

- Improved weekly recurrence summaries to clearly describe selected weekdays while preserving familiar weekly phrasing.

## [v1.6.2] - 2026-10-09

- Fixed calendar view switching by removing conflicting `hidden` attributes from the view panels.

## [v1.6.1] - 2026-10-05

- Changed the event address field to a multiline textarea.
- Improved accessibility in the calendar agenda view.

## [v1.6.0] - 2026-09-24

- Added keyboard navigation to the calendar grid.

## [v1.5.6] - 2026-09-16

- Added an optional contact phone number field, displayed as a clickable link on single-event pages.

## [v1.5.5] - 2026-08-20

- Added event icons and updated calendar text and styling.

## [v1.5.0] - 2026-08-20

- Added a configurable display window for recurring events on single-event pages.
- Fixed calendar “show more” behavior, including occurrence placement and button alignment.
- Updated calendar view-switcher styling.

## [v1.4.5] - 2026-08-19

- Improved identification of occurrences belonging to a recurring series.
- Restyled the calendar/list view switcher.
- Fixed release archives to include the plugin in a top-level `aa-events` folder.

## [v1.4.1] - 2026-08-19

- Hid the legacy Event Date & Time picker on event editing screens.

## [v1.4.0] - 2026-08-19

- Limited calendar day cells to three events and added an overflow link to view all events for that day.
- Fixed the back-to-calendar link so it no longer retains an outdated day selection.

## [v1.3.0] - 2026-08-17

- Added recurring event schedules with daily, weekly, monthly, and yearly patterns.
- Added recurrence options and validation to the Occurrences editor.
- Marked generated occurrences with a “Recurring” badge.

## [v1.2.8] - 2026-08-06

- Changed the event address field from a textarea to a WYSIWYG editor.

## [v1.2.7] - 2026-07-30

- Added synchronized highlighting and interaction for calendar segments representing the same multi-day event.
- Added styling for event registration links.

## [v1.2.6] - 2026-07-30

- Added an event registration link field and displayed registration links in event templates.
- Improved event templates and related styling.
